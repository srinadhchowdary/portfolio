# UI/UX Skill Module

## RESPONSIBILITIES

- Create premium modern UI
- Maintain visual consistency
- Build reusable design system
- Ensure elegant layouts
- Maintain modern spacing/typography

---

# DESIGN STYLE

Preferred:
- Dark theme
- Minimal UI
- Soft shadows
- Light glassmorphism
- Smooth gradients
- Clean typography
- Modern portfolio style

Avoid:
- Overcrowded layouts
- Harsh colors
- Heavy gradients
- Old-fashioned styling
- Inconsistent paddings

---

# UI RULES

- Maintain consistent spacing scale
- Use reusable theme tokens
- Use Chakra UI theme customization
- Maintain visual hierarchy
- Use clean card layouts
- Ensure balanced white space

---

# TYPOGRAPHY

Use:
- Clear heading hierarchy
- Responsive font sizing
- Readable line heights
- Consistent font weights

---

# COLOR RULES

- Use limited palette
- Maintain accessibility contrast
- Use accent colors carefully
- Avoid neon overload
