# Responsive Design Skill Module

## RESPONSIBILITIES

- Build mobile-first layouts
- Ensure perfect responsiveness
- Prevent layout breaking
- Maintain responsive typography

---

# BREAKPOINT SUPPORT

Support:
- 320px mobile
- Tablets
- Laptops
- Large monitors
- 4K displays

---

# RESPONSIVE RULES

- No horizontal scroll
- Flexible grids
- Responsive navbar
- Responsive cards
- Responsive typography
- Adaptive spacing

---

# LAYOUT RULES

- Prefer CSS Grid/Flexbox
- Use responsive Chakra props
- Maintain proper padding
- Avoid fixed widths

---

# MOBILE RULES

- Optimize touch interactions
- Ensure readable font sizes
- Proper button spacing
- Smooth navigation experience
