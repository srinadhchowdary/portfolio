# Code Quality Skill Module

## RESPONSIBILITIES

- Maintain production-grade code
- Ensure scalability
- Improve maintainability

# CODE RULES

- Functional components only
- Hooks-based architecture
- Reusable utilities
- Clean imports
- Consistent naming

---

# STRUCTURE RULES

- Keep files modular
- Avoid massive components
- Separate business logic
- Reuse constants/configs

---

# CLEAN CODE RULES

- Avoid dead code
- Avoid duplication
- Use meaningful naming
- Keep functions focused
- Maintain readability

---

# PRODUCTION RULES

- Write scalable code
- Maintain consistency
- Optimize maintainability
- Keep architecture extensible
